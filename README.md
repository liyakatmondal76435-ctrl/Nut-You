# Nut-You - Mindful Habit Tracker 🌿

Nut-You is a modern, private, offline-first Android application built with **Jetpack Compose** and **Material 3 Expressive Design**. It helps users manage urges, practice self-control, and track clean streaks with total privacy.

## ✨ Features
- ⏱️ **Live Clean Timer**: Real-time streak tracking in Days, Hours, Minutes, and Seconds.
- 🧘 **SOS Urge-Breaker**: Interactive guided breathing visualizer and motivational support.
- 📊 **Stats & History**: Track milestones, badges, and detailed relapse logs with trigger tags.
- 🔒 **100% Offline & Private**: Built on Room Database with zero data leaving your device.
- 🎨 **Material 3 Expressive**: Dynamic Color support (Android 12+ wallpaper dynamic theme) & smooth physics animations.

## 🛠️ Tech Stack
- **Language**: Kotlin 100%
- **UI Framework**: Jetpack Compose (Material 3 Expressive)
- **Architecture**: MVVM
- **Database**: Room DB
- **Target Android**: Android 12 (API 31) to Android 15/17 (API 35+)
